# MyTailLog brand assets

Logo files for partners and integrations (e.g. MyFlightBook). Served at
`https://mytaillog.com/brand/<file>`. Free to use to link to or represent a
MyTailLog integration; don't modify the mark's proportions or colors.

| File | Use |
|---|---|
| `mytaillog-mark.svg` / `.png` (500²) | Mark only — avatars, app icons, favicons, square tiles |
| `mytaillog-logo-dark.svg` / `.png` (1260×330) | Full lockup for **dark** backgrounds (light wordmark) |
| `mytaillog-logo-light.svg` / `.png` (1260×330) | Full lockup for **light** backgrounds (dark wordmark) — use this on MyFlightBook's site |

All SVGs/PNGs have a **transparent** background.

## Colors
- Mark gradient: `#5aa9ff` → `#8ec8ff`
- Ink (dark bg wordmark): `#e9eef5`
- Ink (light bg wordmark): `#0a0d13`
- App background (if you need a solid tile): `#0a0d13`

## Type
Wordmark is **Space Grotesk Bold**. The SVGs reference the font by name with a
sans-serif fallback, so they render best where Space Grotesk is available (the
PNGs are already rasterized with it). Need the wordmark as **outlined paths**
(font-independent) or other formats/sizes? Ask and we'll provide them.

## Clearspace
Keep padding around the logo of at least the height of the mark's triangle.
Don't recolor, rotate, add effects, or place the light-bg lockup on a dark
background (use the dark-bg variant instead).
